# Модели машинного обучения

## Идентификация растений

Файл: `plant_identification_model.tflite`

**Статус:** пока отсутствует. Приложение работает в mock-режиме.

**Как получить реальную модель:**

1. Перейдите в папку `ml/` в корне проекта.
2. Подготовьте датасет (папки с изображениями по классам).
3. Запустите обучение: `python train_model.py`
4. Сконвертируйте в TFLite: `python convert_tflite.py`
5. Скрипт автоматически положит модель в эту папку.

**После этого** приложение автоматически подхватит модель при следующем
запуске. Ничего в коде менять не нужно.

## Формат модели

- Вход: `[1, 224, 224, 3]` (float32 или uint8 в зависимости от квантования)
- Выход: `[1, N]` — вероятности классов (softmax)
- Метки: `labels.txt` (по одной на строку, соответствуют выходам)
