Политика конфиденциальности приложения «Карманный ботаник»

Дата последнего обновления: 20 сентября 2026 г.

1. Общие положения

Настоящая Политика конфиденциальности (далее — «Политика») описывает порядок обработки и защиты информации о пользователях (далее — «Пользователь»), которую Оператор получает при использовании мобильного приложения «Карманный ботаник» (далее — «Приложение»).

Используя Приложение, Пользователь выражает согласие с условиями настоящей Политики. В случае несогласия Пользователь должен прекратить использование Приложения.

2. Сведения об Операторе

Оператор: Физическое лицо (разработчик приложения «Карманный ботаник»)

Контактный e-mail для обращений: pocketbotanist.app@yandex.ru

3. Какие данные обрабатываются и с какой целью

Приложение обрабатывает следующие категории данных исключительно для обеспечения работы его функций:

  • Данные, которые вы предоставляете добровольно:
    • Названия растений, фотографии растений, записи об уходе, которые вы вносите в Приложение. Эти данные хранятся только локально на вашем устройстве и не передаются Оператору.
  • Данные, доступ к которым вы разрешаете:
    • Камера и галерея: Приложение запрашивает доступ к камере и галерее только в момент, когда вы сами хотите сделать или выбрать фотографию растения. Фотографии обрабатываются локально.
    • Геолокация: Приложение запрашивает доступ к вашему местоположению только для получения прогноза погоды и предоставления более точных рекомендаций по уходу. Координаты не сохраняются на постоянной основе и не передаются Оператору.
  • Данные, собираемые автоматически:
    • Аналитика (AppMetrica): Приложение использует сервис аналитики AppMetrica (ООО «Яндекс») для сбора анонимной статистики об использовании Приложения (например, количество запусков, ошибки). Это помогает нам улучшать Приложение. Сбор данных осуществляется в обезличенном виде.

4. Передача данных третьим лицам

Оператор не продает и не передает ваши персональные данные третьим лицам, за исключением следующих сервисов, которые используются для работы Приложения:

  • Open-Meteo (open-meteo.com): Для получения прогноза погоды Приложение отправляет на сервер Open-Meteo только ваши географические координаты (широта и долгота). Данные о вашем устройстве или личности не передаются.
  • AppMetrica (appmetrica.yandex.ru): Передает обезличенные данные о событиях в Приложении (запуски, ошибки) для статистики.

5. Хранение и защита данных

Все данные, которые вы вносите в Приложение (растения, записи об уходе), хранятся исключительно в локальной базе данных на вашем устройстве. Оператор не имеет к ним доступа. При удалении Приложения эти данные также удаляются.

Передача данных на сторонние сервисы (Open-Meteo, AppMetrica) осуществляется по защищенному протоколу HTTPS.

6. Ваши права

Вы имеете право:

  • Прекратить использование Приложения в любой момент.
  • Удалить все свои данные, удалив Приложение с устройства.
  • Отозвать разрешения (на доступ к камере, геолокации) в настройках вашего устройства.
  • Обратиться к Оператору по адресу электронной почты, указанному в разделе 2, для получения информации об обработке данных.

7. Изменения в Политике

Оператор может обновлять настоящую Политику. Актуальная версия всегда доступна по адресу, с которого вы перешли на эту страницу. Продолжение использования Приложения после внесения изменений означает ваше согласие с новой редакцией Политики.
