# План разработки офлайн-приложения «Карманный ботаник» — пошаговые промпты для ИИ

## Как использовать этот документ

Данный файл содержит последовательность промптов (инструкций) для ИИ-ассистента. Каждый промпт — это отдельный шаг разработки. Вы копируете текст промпта и отправляете его в чат с ИИ (например, мне). ИИ выполняет задачу и возвращает результат. После успешного выполнения переходите к следующему промпту.

Все промпты разбиты на фазы. В начале каждой фазы указана её цель и общий срок. Внутри фазы промпты идут в порядке выполнения.

**Важно:** Перед началом убедитесь, что у вас настроена среда разработки (Flutter SDK, IDE, эмуляторы) и есть доступ к необходимым сервисам (GitHub, App Store Connect, Google Play Console).

## Фаза 3. Календарь и напоминания (3 недели)

### Промпт 3.1. Расчёт графика полива

**Контекст:** У каждого растения есть `watering_frequency_days` и `last_watered_at`. Необходимо вычислять `next_water_due`.

**Задача:** Написать сервис `CareScheduler`, который:

- рассчитывает `next_water_due = last_watered_at + watering_frequency_days * 24 ч`.
- при создании растения, если `last_watered_at` не задан, устанавливает `next_water_due = created_at + watering_frequency_days`.
- при изменении частоты полива пересчитывает `next_water_due`.
- предоставляет список растений, требующих полива сегодня/просроченных.

**Ожидаемый результат:** Класс с методами, юнит-тесты.

**Критерии готовности:** Расчёт корректен, учитывает повторный полив (если полить раньше срока, следующий сдвигается).

## Фаза 4. AI-идентификация растений (4 недели)

### Промпт 4.1. Подготовка датасета и обучение модели идентификации

**Контекст:** Нужна модель машинного обучения для классификации изображений растений. Модель должна работать офлайн на устройстве.
